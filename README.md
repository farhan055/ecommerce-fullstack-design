# E-commerce Full-Stack Design
This project is being developed as part of the DevelopersHub Corporation internship task.
It is a fully functional e-commerce web application built using the MERN stack (React, Node.js, Express.js, MongoDB).

## Weekly Milestones
* **Week 1:** Project Setup and Static Frontend Development.
* **Week 2:** Backend Setup and Dynamic Integration (APIs).
* **Week 3:** Additional Features (Auth, Cart Mgmt) and Final Deployment.
